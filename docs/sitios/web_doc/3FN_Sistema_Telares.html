Tercera Forma Normal (3FN)

Sistema de Telares · Grupo 5 · InfoB · 2026

Para cumplir la 3FN cada tabla debe cumplir: 1FN (sin grupos repetidos, un valor por celda) → 2FN (cada campo no-clave depende de toda la clave primaria) → 3FN (ningún campo no-clave depende de otro campo no-clave, sin dependencias transitivas).
